# AI-Powered E-Commerce DevOps & Cloud-Native Delivery Platform

## Project Objective
Build a secure, automated, observable and repeatable DevOps delivery
platform around an existing e-commerce application.

## Technology Stack
- Linux, Git and GitHub
- Bash
- Docker and Docker Compose
- Jenkins CI/CD
- Terraform and Ansible
- Kubernetes and Helm
- Prometheus and Grafana
- ELK centralized logging
- DevSecOps security scanning
- Cloud deployment
- AI-assisted incident analysis

## Repository Structure
- app/: Existing e-commerce application
- scripts/: Bash automation
- docker/: Container configuration
- jenkins/: CI/CD supporting files
- terraform/: Infrastructure as Code
- ansible/: Server configuration
- kubernetes/: Kubernetes manifests
- helm/: Helm charts
- monitoring/: Monitoring configuration
- logging/: Centralized logging configuration
- security/: Security reports and configuration
- docs/: Project documentation
- screenshots/: Submission evidence
